# 公開サイトでの運営者の表記

2026-11-09 の運営者の指示による。

- 「阿部善博が確認した情報だけを載せています」ではなく「運営者が確認した情報だけを載せています」とする。他の部分も同様
- 賛否などは、**運営者として行ったものは「運営者」、議員個人として行ったものは「議員個人名」** の原則とする

## 決まり

1. **運営者としての行為**（サイトの運営：確認する・載せる・回答する・返信する・意見や質問を受け取って対応する・作る）は、主語を「運営者」と書く。名前を添えない（「運営者（○○）」とも書かない）
2. **議員個人としての行為**（議案への賛否、議会での質問）は、議員の名前で示す
   - 議案のページの「○○の賛否」（`operator.name`）
   - 「議会での質問」は議員の名前で載せ、運営者本人の質問には「運営者」と添えるだけ
3. **運営者がだれかを示す所**には名前を出す
   - トップの「このサイトの運営者」欄（写真・肩書・名前と、その下の「公式サイトではありません」の注記）
   - トップの「これからの運営」（いまは○○が個人で立ち上げたこと。サイト設定 `site.collaboration_md`）
   - 意見・質問フォームの案内「意見や質問は、運営者である○○に届き、運営者が対応します。あらかじめご了承ください。」（投稿の送り先を示すため）
   - 利用規約の「○○（以下「運営者」といいます。）」
   - フッターの「（運営：○○）」、メニューの「改変：○○」（AGPL の改変の表示）、公開準備中ページの「運営：○○」
   - 検索エンジン向けのページ情報（作者・発行者）

## 2026-11-09 に直した所

- 「本日は」欄・会期の欄の「○○が確認した情報だけを載せています」
- 「このサイトについて」の「本サービスは○○が…元に作成したもの」、「サイト名について」の「○○が個人で作って運営しています」
- 議案のページ：掲載コンテンツについて、意見（「○○が内容を確認」「○○からの返信」）、質問と回答、パブリックコメントの案内
- 質問と回答のページの説明、AI インタビューの説明・同意・完了・公開／非公開の確認
- サイト設定の既定文：掲載方針・正式な手続きの違い・インタビューの同意文・通年議会の説明
- 保存済みの設定の文は、マイグレーション `20261109100000_site_texts_operator_role.sql` で同じように直す
- 賛否の見出しは、いったん「運営者の賛否」にしたが、原則 2 により「○○の賛否」に戻した
