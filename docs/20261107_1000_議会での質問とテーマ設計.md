# 議会での質問とテーマ（設計と運用）

議案以外の議論（代表質問・個人質疑・一般質問）を、議会が公表する通告一覧から載せる。
あわせて、タグを「テーマ」として公開し、議案と議会での質問をテーマごとに見られるようにする。

## 載せ方の約束

- 全議員の質問を、公式の順番（順位）・同じ形式で載せる。運営者本人の質問も同じ形式で、「運営者」と添えるだけ
- 項目は通告の文言のまま（言い換えない・要約しない）。折り返しだけつなぐ
- 答弁の要旨は載せない。中継の録画と会議録へのリンクを付ける
- 取り込んだ質問は仮登録（非公開）。運営者が通告一覧の PDF と見比べて「確認して公開」したものだけを出す
  （公開には確認日時が要る。DB の制約 `council_questions_published_requires_confirmation`）

## データ

- `council_questions`：1 行 = 1 人の 1 回の質問。鍵は（定例会議 `meeting_key`、一覧の種類 `list_kind`、順位 `order_no`）
  - `items`：項目の木 `[{label, level, text, children}]`。段は 1 → (1) → ア → （ア） → ａ → （ａ）
  - `bill_refs`：項目に出てくる番号（例: 議案第99号）。議案のページとつなぐ（`令和8年議案第99号` = `bills.bill_number`）
  - `site_snapshot`：前回の取込で読めた内容。変更の検出に使う
  - `operator_edited_at`：運営者が通告の内容（氏名・会派・方式・質問日・項目）を直した日時。区分・リンク・テーマだけの変更では付けない
  - `pending_update`：公開済み・手直し済みの行で、公式の内容が変わった／無くなったときの保留
- `tags.is_theme` / `tags.theme_order`：タグをテーマとして公開するか、並び順
- `council_question_themes`：質問の大きな項目（「1」「2」…）とテーマのひも付け。運営者だけが付ける

## 取込（管理画面「議会での質問」）

1. 「サイト設定」→「リンク」の「議案のページ」（相模原市議会の「提出議案・発言通告」ページ）から、
   通告一覧（代表質問・個人質疑、一般質問）と一般質問順位の PDF を探す。URL を直接指定することもできる
2. PDF の文字を位置ごとに読み（`unpdf`）、画面に出ない重ね文字（切り抜きの外の文字）は捨てる
3. 「順位N 質問者N番 氏名（会派）（方式）」の行で質問者を分け、番号で項目の木にする
4. 一般質問順位の表から、質問日を入れる（日付のセルの高さの真ん中で行をまとめる）
5. 既存の行と比べる
   - 無い → 仮登録で追加
   - 同じ → そのまま
   - 仮登録のまま → 公式の内容で置き換える
   - 公開済み・手直し済み → 書き換えず、`pending_update` に入れて知らせる（違う行に色を付けて見比べられる）
   - 公式の一覧から消えた → 仮登録なら削除、公開済み・手直し済みなら知らせる

## 公開サイト

機能フラグ `features.council_questions` がオフのあいだは、どのページも 404 で、メニューにも出ない。

- `/council-questions`：いちばん新しい定例会議の質問（区分ごと、一般質問は質問日ごと）と、ほかの定例会議への入口
- `/council-questions/[meetingKey]`：定例会議ごと
- `/council-questions/[meetingKey]/[questionId]`：1 人分（細目まで、中継・会議録・通告一覧へのリンク、取り上げた議案、テーマ）
- `/council-questions/members/[memberName]`：議員ごとの履歴
- `/themes`、`/themes/[themeId]`：テーマごとの議案と議会での質問
- 議案のページ：「この議案を取り上げた議会での質問」（通告にその議案の番号が出てくる質問）
- トップ：いちばん新しい定例会議への入口

## 運用の手順

1. DB を更新する（`npx supabase db push`）
2. 「サイト設定」→「運営者」→「議会での氏名（通告一覧の表記）」に、通告一覧どおりの氏名を入れる（「運営者」の表示に使う）
3. 通告一覧が議会サイトに載ったら、「議会での質問」→「通告一覧を取り込む（仮登録）」
4. PDF と見比べて「確認して公開」（一覧でまとめて選べる）。読み取りが崩れたところは、編集画面で直す
5. 「タグ管理」で、テーマにするタグの「テーマのページを公開する」をオンにし、説明文と並び順を入れる。
   質問の編集画面で、大きな項目ごとにテーマを選ぶ
6. 最初の質問を公開したら、「サイト設定」→「機能」→「議会での質問・テーマ」をオンにする
7. 質問日のあとに、中継の録画の URL を、会議録が公開されたら会議録の URL を入れる
