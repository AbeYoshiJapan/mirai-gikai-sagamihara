# 投稿の削除と投稿のルール

## 目的

意見・質問のフォームに届いた投稿のうち、スパム・広告や個人情報を含むものなど、残しておけない投稿を管理画面から消せるようにする。
あわせて、どんな投稿を削除するかを、投稿する人に前もって示す。

これまでは「非公開」「終了（回答しない）」で一覧から外せるだけで、投稿そのもの（本文・返信先・IP のハッシュ）は残っていた。

## 削除の対象

利用規約 第1条（禁止事項）に当たる投稿。

- 投稿の本文に個人情報（ご自身のものを含む）を書き込んだもの
- 他人の名誉や信用を傷つける内容、差別的な内容
- 法令や公序良俗に反する内容（児童ポルノなど）や、そうした内容へのリンク
- コンピュータウイルスなどの不正なプログラム、偽のサイト（フィッシングサイトなど）へのリンクなど、安全を損なうおそれのある内容
- 広告・宣伝、営業・勧誘、選挙運動を目的としたもの
- 本サービスの趣旨（議会や市、本サービスに関すること）と関係のないもの
- 同じ内容のくり返し、機械的な大量投稿など、運営を妨げるもの

## 管理画面

- 「意見・質問」の各投稿（「議案への意見」「質問・窓からの意見」の両方）に「削除」ボタンを付ける。
- 押すと確かめる画面を出す。本文を見せ、「本文・返信先・返事など、この投稿に関するものがすべて消え、元に戻せません」と示す。公開中なら「サイトからもすぐに消えます」と添える。
- 確かめる画面に、違法な内容（児童ポルノなど）やそれへのリンクは、削除の前に警察庁のインターネット・ホットラインセンターなどへの通報も検討するよう一行添える（消すと URL がわからなくなるため）。
- 削除は行ごと消す（`reader_questions` / `reader_opinions` の delete）。ほかの表から参照されていないので、連動して消えるものはない（「PR・広報」の投稿記録は話題の ID を文字で持つだけなので残る）。
- 公開中だった投稿を消したときは、公開サイトのキャッシュ（`READER_POSTS`）を消して、すぐに見えなくする。

## 公開サイトでの示し方

| 場所 | 書くこと |
|---|---|
| 各フォームの下の注意書き（議案ページ、よくある質問、トップの窓） | 「個人情報は書かないでください。広告や関係のない内容など、利用規約に反する投稿は削除します。」（「利用規約」にリンク） |
| 利用規約 第1条（禁止事項） | 上の「削除の対象」の一覧 |
| 利用規約 第2条（投稿の削除・違反への対応） | 予告なく削除すること、削除したことや理由はお知らせしないことがあること、法令に反する内容は必要に応じて関係機関に通報すること、くり返す方の利用を制限することがあること |
| 利用規約 第3条5 | 公開中の投稿に個人がわかる内容が含まれているなど、気づいた点は窓口へ。運営者が確認し、必要に応じて公開をやめ、または削除する |
| 利用規約 第8条（お問い合わせ） | 規約や投稿に関するお問い合わせ、情報の誤りや不確かな点のお知らせを受け付ける |
| プライバシーポリシー 7 | 禁止事項に当たる投稿は、保管期間（4 年）にかかわらず削除する |
| プライバシーポリシー 8（お問い合わせ） | 投稿に関するお問い合わせ、情報の誤りや不確かな点のお知らせを受け付ける。気づいた点があれば知らせてもらい、運営者が確認して必要に応じて公開をやめ、または削除する |

### 「ご自身の投稿の削除のご相談」をやめた理由

ログインがなく、投稿した本人かを確かめる方法がない。そのため、「ご自身の投稿の削除」を受け付けるという書き方はやめた。
代わりに、だれからでも「お気づきの点」を知らせてもらい、運営者が内容を見て判断する書き方にした。

## 反映

- 利用規約・プライバシーポリシーの既定文を直した（`packages/shared/src/site-settings/templates.ts`）。
- 既定文を保存したまま使っている設定にも効くよう、`supabase/migrations/20261109130000_legal_texts_post_deletion.sql` で該当の文だけを置き換える。運営者が書き換えた文は一致しないので変わらない。
  - 手元で、旧い既定文を保存した状態にこの migration を当てると、新しい既定文と同じになることを確かめた。
- 反映には `npx supabase db push --remote` が必要。

## 残っていること

- プライバシーポリシーの「取得から 4 年で削除」を自動で行う仕組みはまだない（最初の投稿が 4 年を迎えるのは 2030 年）。
- 議案ページの「誤り報告」には、まだ削除ボタンがない。
