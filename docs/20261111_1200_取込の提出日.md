# 取込で入れる議案の提出日

## 背景

相模原市議会では、議案は基本的に定例会議の初日に提出（提案）される。途中提案もある。
付議事件一覧は開会前に「令和８年１１月１０日現在」の形で載るが、この日付は一覧を作った日で、提出日ではない。開会前の議案は示されているだけで、提案されるのは開会後である。

これまでの取込は、議案書が無いと一覧の日付を提出日に入れていた。
しかも提出日は空のときしか埋めないので、後で議案書を取り込んでも、一覧の日付が残っていた。

## 決めたこと

提出日は、議案書に書かれた日付（「令和８年１１月１７日提出」）を正とする。
議案書がまだ無い議案は、その定例会議の初日を仮の提出日にする。

| 場面 | 入れる提出日 |
|---|---|
| 新しい議案・議案書あり | 議案書の日付 |
| 新しい議案・議案書なし | 定例会議の初日 |
| 新しい議案・議案書なし・会議中に追加された議案（一覧の ※）で一覧の日付が初日より後 | 一覧の日付 |
| 新しい議案・議案書なし・定例会議の期間が分からない | 一覧の日付（差分確認に注意を出す） |
| 既存の議案・提出日が空 | 上と同じ |
| 既存の議案・議案書の日付と違う | 議案書の日付にする案を出す（「提出日（議案書の日付）」） |
| 既存の議案・議案書なし・いまの提出日が一覧の日付 | 定例会議の初日にする案を出す（「提出日（定例会議の初日）」）。前の取込で入った仮の日付を直すため |
| 既存の議案・議案書なし・それ以外の日付 | 変えない（運営者が入れた日付を守る） |

案は差分確認の一覧に出し、運営者が議案ごとに選んで適用する。適用した後も、議案の編集画面で提出日を直せる。

## 定例会議の初日の求め方

取込画面で選んだ会期の「定例会議などの期間」（会期管理で入れる `diet_sessions.meeting_periods`）から探す。

1. 一覧の会議名（例「12月定例会議」）と同じ名前の期間（全角数字・空白の違いはならす）
2. 一覧の日付を含む期間
3. 一覧の日付から 31 日以内に始まる期間

見つからなければ一覧の日付を使い、差分確認に「会期管理でこの会期に定例会議の期間を入れると、初日を提出日にします」と注意を出す。
見つかったときは、差分確認に「提出日：議案書があれば議案書の日付、まだ無ければ12月定例会議の初日（2026-11-17）にします。」と説明を出す。

## 実装

- `packages/shared/src/import/submitted-date.ts`：期間の探し方と仮の提出日（純粋関数・テストあり）
- `packages/shared/src/import/plan.ts`：`planAgendaImport` に会期の期間を渡し、新規の提出日と既存の提出日の案を作る
- `admin/src/features/import`：会期の期間を読み（`findSessionMeetingPeriods`）、差分確認に説明・注意を出す

DB の変更はない。
